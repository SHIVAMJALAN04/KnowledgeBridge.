# Utilities

This folder contains reusable utility functions used throughout KnowledgeBridge.

## Files

- __init__.py – Initializes the utils package.
- asset_checker.py – Contains logic for checking and verifying project assets.
- brand_checker.py – Contains logic for checking brand-related assets.
- helpers.py – Contains common helper functions used across the application.

## Purpose

This folder keeps reusable logic separate from the user interface, making the application easier to organize, maintain, and extend.
